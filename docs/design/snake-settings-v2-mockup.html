신규 "조작" 섹션은 #settings-panel 본문 끝에 additive 삽입. 기존 게임/먹이/아이템/시간 섹션과 게임 오버 메뉴는 마크업·selector 불변. 간격은 전부 --snake-settings-field-gap: 12px.

2. 사운드 토글 — sound-enabled / sound-disabled (색 외 텍스트 구분)

sound-enabled · 켜짐 · aria-checked="true"

트랙 배경 --snake-toggle-on-bg #16a34a + 텍스트 "켜짐". thumb 우측 이동.

sound-disabled · 꺼짐 · aria-checked="false"

중립 트랙 --ctrl-track-bg + 텍스트 "꺼짐". 색만이 아니라 화면 텍스트로 상태를 노출.

4. 설정 닫힘 후 포커스 복원 — settings-open-button 으로 복원

⚙ 설정 버튼 포커스 복원#settings-open-button · focus 復

기존 게임 오버 메뉴 배선(notifySettingsClosed() → settingsBtn.focus())을 재사용. 신규 배선을 추가하지 않고, 패널 닫힘 시 키보드 포커스를 #settings-open-button 으로 되돌린다.
