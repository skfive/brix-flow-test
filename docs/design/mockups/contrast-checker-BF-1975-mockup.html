정적 mockup입니다. 실제 대비율 계산·상태 전이·이벤트 리스너는 developer(contrast-checker/contrast.js)가 구현합니다.

devnote: 아래 3개 스냅샷(idle / valid / error)은 한 문서 안에서 나란히 비교하기 위해 frozen DOM id에 상태 접미사(-idle/-valid/-error)를 붙였습니다. 실제 런타임 페이지(contrast-checker/index.html)는 위젯 인스턴스가 하나뿐이므로 접미사 없이 frozen id (contrast-foreground-input, contrast-background-input, contrast-ratio-value, contrast-aa-result, contrast-aa-large-result, contrast-aaa-result, contrast-preview, contrast-error)를 그대로 1회씩만 사용해야 합니다(mockup 전용 예외).
