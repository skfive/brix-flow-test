Dossier 근거 상태 배지 — 5개 상태 시각 mockup

BF-1341 · route /planning/ · frozen token 준수 · 색상 외 화면 텍스트 + aria-label 노출 (시안 시각화 전용, 런타임 산출물 아님)

1 · loading

근거 상태 확인 중

화면 텍스트 근거 상태 확인 중 + 진행 표시. aria-label="근거 상태 확인 중"

2 · sufficient

근거 충족

텍스트 배지만 노출. 보조 색 --color-evidence-sufficient (#16a34a). aria-label="근거 충족"

3 · insufficient

근거 부족 상세 보기

텍스트 배지 + 상세 보기 링크 활성(키보드 focus 가능, aria-label="근거 상세 보기"). 보조 색 --color-evidence-insufficient (#dc2626).

4 · empty

배지 숨김 — 기존 빈 상태 유지 (접근성 트리에서도 제외)

데이터 없음 → 배지 미노출, 기존 Planning Dossier 빈 상태 그대로.

5 · error

상태를 불러오지 못했습니다

화면 텍스트 상태를 불러오지 못했습니다 + 재시도 가능(→ loading 재진입, 초기값 복구). aria-label 동일.
