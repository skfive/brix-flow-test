1. 6개 상태 (frozen state 모델 · 색상 외 화면 텍스트로 상태명 노출)

state: loading — 초기값

상태 확인 중 대기

state: ready — 종료 가능

종료 준비 완료 종료 진행

state: blocked — blocker 존재 (count 노출)

종료 불가 — blocker 3건 blocker 3건 blocker 보기

state: needs-operator-action — 운영자 조치 필요

운영자 조치 필요 조치하기

state: empty — 대상 데이터 없음

표시할 항목 없음 —

state: error — 조회 실패

상태를 불러오지 못함 다시 시도

상태 색상 토큰: --color-status-ready #16a34a, --color-status-blocked #dc2626, --color-status-neutral #64748b · 상태는 좌측 보더 + 상태 점에만 색상 적용, 상태명은 항상 배지 텍스트로 노출(색상 비의존).
