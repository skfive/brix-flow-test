접근성·반응형·후조건 요약 (frozen 계약 시각 표현):

· 모드/난이도 버튼 = 명시적 aria-label · 방향키 ↑ ↓ 이동 + Enter 선택 · 포커스 링 --color-menu-focus(#00e5ff)

· #winner-banner = aria-live="polite" → "당신 승리 / CPU 승리 / 무승부" 텍스트를 스크린리더가 읽음(결과를 색만으로 구분하지 않음, WCAG 1.4.1)

· 모든 상태는 색 + 화면 텍스트(상태명) + 접근성 이름 3중 채널로 구분 — HUD 는 "당신"/"CPU" 라벨로 두 뱀을 색 없이도 구분

· 후조건(INV-D): game-over 재시작 / 난이도 취소(Esc) → #winner-banner 비우고 mode-selection 초기값 복귀 + 메뉴 컨트롤 재활성(키보드 사용 가능)

· 반응형: 풀스크린 캔버스 ≥320px overflow 0(computeBoardMetrics 재사용) · 세로 화면에서도 메뉴가 잘리지 않고 --space-menu-gap(16px) 세로 간격 유지

· prefers-reduced-motion: reduce → 먹이 맥동 비활성(정적 렌더), 게임 이동은 유지
