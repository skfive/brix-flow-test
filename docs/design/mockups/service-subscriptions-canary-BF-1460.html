표시할 구독이 없습니다

#subscription-add-submit은 aria-label="구독 추가"를 갖는다. adding 상태에서도 이 라벨은 고정되고 표시 텍스트만 "추가 중…"으로 바뀐다.

#subscription-filter-status는 연결된 <label> 텍스트 "상태 필터"를 갖는다.

.subscription__item은 tabindex="0"으로 Tab 순회 가능하다. 해제 control(.subscription__item-remove, 비-frozen 보조 class)은 서비스명이 포함된 aria-label을 갖는다.

2. 상태 갤러리 (6개 상태 시각 참조)

idle → adding → (subscribed | error). 해제 시 idle → removed(→ empty). 색상뿐 아니라 상태명이 화면 텍스트에 포함되어 색맹 사용자도 텍스트로 상태를 구분할 수 있다. subscribed/removed/error 문구는 designer 보조 요소인 .subscription__status(aria-live="polite", 참조용 스냅샷이므로 data-state 속성으로 구분)에 표시된다.
