참조 — 접근성 · reduced-motion 규격 (명세 §8)

키보드 · 포커스 · aria-live · reduced-motion · 대비

  • Tab 순서 = DOM 순서: 전체 새로고침 → 필터 세그먼트(좌→우) → 저장소 행(위→아래, 지금 확인/재시도). 전 인터랙티브는 네이티브 <button>.
  • 포커스: 전 인터랙티브 :focus-visible 2px primary outline(전역 outline:none 금지). 이 mockup 에서 Tab 으로 확인 가능.
  • aria-live: 헤더 role="status" aria-live="polite"(시작/완료/전체 결과) + 충돌·실패 도달은 aria-live="assertive". 확장 영역은 role="alert".
  • reduced-motion: ◐ 회전·펄스는 prefers-reduced-motion 에서 정지, 라벨 확인 중… 텍스트가 진행을 전달(모션 없이도 인지). OS 설정을 켜고 새로고침하면 회전이 멈춥니다.
  • 색 비의존: 6-state 모두 색 + 한글 라벨 + glyph + 좌측 rail 두께(개입 필요한 충돌·실패만 4px)로 3중 인코딩. 배지 role="img" + aria-label. 충돌(violet)↔실패(red)는 hue·glyph(⇆↔⚠)로도 구분.
  • WCAG 대비(명세 §8.5, sRGB 상대휘도 계산): 6-state 배지 전부 ≥4.5:1 — 미확인 9.4 / 최신 4.9 / 지연 6.7 / 동기화중 4.9 / 충돌 6.1 / 실패 4.6. (planner §11 요건 충족, 초안의 warning 2.9:1 대체.)
