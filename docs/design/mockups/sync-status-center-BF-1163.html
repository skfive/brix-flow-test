참조 — 접근성 · reduced-motion 규격 (명세 §8)

키보드 · 포커스 · aria-live · reduced-motion

  • Tab 순서 = DOM 순서: 전체 새로고침 → 필터 세그먼트(좌→우) → 저장소 행(위→아래, 동기화/재시도). 전 인터랙티브는 네이티브 <button>.
  • 포커스: 전 인터랙티브 :focus-visible 2px primary outline(전역 outline:none 금지). 이 mockup 에서 Tab 으로 확인 가능.
  • aria-live: 헤더 role="status" aria-live="polite"(시작/완료/전체 결과) + 실패는 aria-live="assertive". 오류 확장은 role="alert".
  • reduced-motion: ◐ 회전·펄스는 prefers-reduced-motion 에서 정지, 라벨 동기화 중… 텍스트가 진행을 전달(모션 없이도 인지). OS 설정을 켜고 새로고침하면 회전이 멈춥니다.
  • 색 비의존: 모든 상태는 색 + 한글 라벨 + glyph + 좌측 rail 두께(오류만 4px)로 3중 인코딩. 배지 role="img" + aria-label.
