타이핑 속도 테스트 UI mockup — BF-2029 / BF-2030

frozen UI 계약(DOM ID / class / token / 상태)을 그대로 반영한 시각 mockup. idle / running / finished 3개 상태를 정적 스냅샷으로 나열했다. 실제 인터랙션(JS)은 없으며, 문장·입력값·통계는 placeholder 예시다. 실제 구현은 typing/index.html, typing/style.css, typing/typing.js (developer 소유)에서 진행한다.

char-pending (미입력) char-current (현재 위치) char-correct (정확) char-incorrect (오타)
1. idle (대기) — 타이머 시작 전, 문장 첫 글자만 char-current
