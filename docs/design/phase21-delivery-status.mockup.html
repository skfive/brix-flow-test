1. 상태 4종 (idle / loading / delivered / error)

idle
상태 확인 대기

최초 진입 · 초기화/취소/실패 후 복귀 지점. refresh 활성.

loading
전달 상태 확인 중…

진행 표시 노출. refresh 비활성(중복 실행 방지).

delivered
전달 완료 2026-08-01T03:12:00Z

ISO 8601(UTC) 갱신 시각 표시. refresh 활성.

error
전달 상태를 불러오지 못했습니다

API 실패(5xx/네트워크)·403 권한 거부 공통 문구. refresh 재활성.

정상 흐름: idle → loading(refresh 비활성) → delivered(갱신 시각 표시, refresh 재활성)
전달 상태 확인 중…
5xx / 네트워크 / 403 →
전달 상태를 불러오지 못했습니다
새로고침 재시도 가능 →
상태 확인 대기
실패 흐름: loading → error(refresh 즉시 재활성, 거부 사유 미노출) → 재시도 시 idle 경유 후 재조회
전달 상태 확인 중…
조회 취소(abort) →
상태 확인 대기
취소 흐름: loading 중 abort → 진행 표시 중단 → idle 복귀, refresh 즉시 재활성화 (frozen invariant)
