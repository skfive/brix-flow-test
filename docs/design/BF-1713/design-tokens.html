Star Collector · 디자인 토큰

frozen UI contract (BF-1713 §3.5) 의 색상·타이포·간격·반경 토큰을 :root CSS custom property 로 선언한 시각 카탈로그입니다. 아래 모든 견본은 하드코딩 값이 아니라 선언된 변수를 실제로 참조합니다.

색상 토큰

각 색 면은 대응하는 var(--color-*) 를 직접 참조합니다.

배경

--color-bg

#0f172a

플레이어

--color-player

#38bdf8

별 (star)

--color-star

#fbbf24

위험 (hazard)

--color-hazard

#ef4444

HUD 텍스트

--color-hud-text

#f8fafc

타이포그래피 토큰

글자 크기는 var(--font-title-size) / var(--font-hud-size) 를 직접 참조합니다.

게임 오버

--font-title-size · 40px

점수: 0

--font-hud-size · 20px

간격 토큰

블록 사이 gap 은 var(--space-hud-gap) 를 직접 참조합니다.

--space-hud-gap · 12px

반경 토큰

패널 모서리 반경은 var(--radius-panel) 를 직접 참조합니다.

--radius-panel · 12px

그림자 토큰 (additive — 프로즌 토큰 재정의 아님)

패널 그림자는 var(--shadow-panel) 를 직접 참조합니다.

--shadow-panel · 0 10px 30px rgba(2,6,23,.55)
