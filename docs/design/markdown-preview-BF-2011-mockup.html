마크다운 미리보기 — 시각 mockup (BF-2011 / BF-2012)

이 mockup은 planner가 동결한 UI 계약(DOM id/class/token)을 그대로 사용해 empty-placeholder와 live-preview 두 상태를 정적으로 보여줍니다. 실제 입력 반응형 동작은 없으며, 브라우저 창 폭을 640px 기준으로 좁히면 세로 스택 ↔ 가로 배치 전환을 확인할 수 있습니다.

상태 1 — data-state="empty-placeholder" (AC1: 초기 로드 / 빈 입력)

텍스트영역이 비어 있을 때. 안내 문구가 화면에 보이는 텍스트로 노출되며 색상에만 의존하지 않습니다.

empty-placeholder
마크다운을 입력하면 미리보기가 표시됩니다

상태 2 — data-state="live-preview" (AC2: 실시간 변환 / AC4: XSS 방지)

지원 문법이 입력된 뒤 renderMarkdown(text) 결과가 표시된 상태. 헤딩·굵게·기울임·인라인 코드·코드 블록·목록·링크·문단·XSS 이스케이프 예시를 모두 포함합니다.
