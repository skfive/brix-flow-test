숫자 야구 — 디자인 토큰

BF-1773 · frozen 토큰 계약(implementation-plan.md §3.4)의 시각 정의. 아래 모든 견본은 :root CSS custom property로 렌더링됩니다. developer 는 동일 변수명을 하드코딩 없이 참조합니다.

색상 (Color)

--color-bg #0f172a · 배경
--color-surface #1e293b · 카드/표면
--color-text #f8fafc · 본문 텍스트
--color-strike #22c55e · 스트라이크
--color-ball #eab308 · 볼
--color-out #ef4444 · 아웃

배경(#0f172a) 위 텍스트(#f8fafc) 대비 > 4.5:1 — WCAG AA 본문 기준 충족. 판정 색상(strike/ball/out)은 색상만으로 구분하지 않고 상태명 텍스트를 항상 병기합니다(§3.5).

판정 색상 매핑 (Strike / Ball / Out)

스트라이크 --color-strike · 숫자·위치 모두 일치
볼 --color-ball · 숫자 있으나 위치 다름
아웃 --color-out · 일치 숫자 없음

타이포그래피 (Typography)

디스플레이 지표(판정 결과)만 frozen 토큰 --font-size-display로 고정됩니다. heading/body/caption 크기는 시안 권장값입니다.
