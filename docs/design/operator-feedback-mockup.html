브라우저 창 폭을 480px 미만으로 줄이면 아래 카드의 액션 버튼이 실제로 세로 스택된다 (frozen 반응형 계약 실동작 확인용). mockup은 정적 파일이므로 상태 전이 자체는 JS 없이 아래 "2. 상태 갤러리"에서 6개 상태를 모두 확인한다.
