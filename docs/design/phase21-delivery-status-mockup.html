1. 상태별 배지 (idle / loading / success / error)

idle — 화면 텍스트 "대기 중" · neutral #64748b
대기 중 갱신 시각 미확정
loading — 화면 텍스트 "불러오는 중" · neutral · control 진행 표시
불러오는 중 갱신 중…
success — 화면 텍스트 "정상" · success #16a34a
정상 마지막 갱신: 2026-07-30 09:00
error — 화면 텍스트 "오류" · error #dc2626
오류 마지막 갱신: 2026-07-30 08:41

모든 상태는 색상 외 화면 텍스트 + 접근성 이름(aria-live)으로 동시에 노출 — 색상만으로 구분하지 않음(AC-6).

2. 상태 전이 & 복원 흐름 (AC-5 · E5 frozen invariant)

새로고침 실행 → 재조회 → 성공/실패
대기 중 → 불러오는 중 → 정상 ／ 오류

새로고침 control 클릭 또는 키보드 Enter/Space → loading 전이 후 delivery-status.json 재조회. loading 중에는 control 진행 표시로 중복 재조회 방지(E4).

실패 · 취소 후 복원 — 상태/진행 초기값 복귀 + 새로고침 재활성화
오류 → (복원) → 대기 중

실패·취소 이후 배지는 idle("대기 중")로 복귀하고 진행 표시가 사라지며, 새로고침 control은 다시 사용 가능해진다(E5 frozen invariant).

3. control 상호작용 상태 (hover / focus / disabled)

<button> 요소로 Enter/Space 키보드 실행 기본 지원(AC-5). focus-visible 아웃라인으로 키보드 포커스 가시화.

4. 반응형 — 320px content overflow 없음 (AC-7)

뷰포트 폭 320px 프레임 — 배지 + 갱신 시각이 flex-wrap으로 overflow 없이 표시
