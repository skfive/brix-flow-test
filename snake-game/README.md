# Snake 게임 (BF-1696)

20x20 격자에서 진행하는 Snake 게임입니다. 빌드 단계 없이 정적 파일만으로 실행됩니다.

## 실행 방법

빌드나 패키지 설치가 필요 없습니다. `snake-game/` 디렉터리를 정적 파일 서버로 서빙한 뒤
`index.html`을 브라우저로 열면 됩니다. 예시:

```bash
# 이 디렉터리(snake-game/)에서
npx http-server -p 8080
# 또는
python3 -m http.server 8080
```

브라우저에서 `http://localhost:8080/index.html`에 접속합니다.

`index.html`을 파일 시스템에서 바로 더블클릭해 열어도 동작하지만(모듈 스크립트가
`file://`에서 차단되는 브라우저가 있을 수 있어), 위와 같은 로컬 정적 서버 사용을 권장합니다.

## 조작법

| 키 | 동작 |
|---|---|
| 방향키(↑↓←→) 또는 W/A/S/D | 이동 방향 전환 (진행 방향의 정반대 입력은 무시됩니다) |
| 일시정지 버튼 | 게임 일시정지 / 재개 토글 |
| 다시 시작 버튼 | 게임을 초기 상태(idle)로 리셋 |

## 게임 규칙

- 먹이를 먹으면 점수가 1 증가하고 몸 길이가 1칸 늘어납니다.
- 새 먹이는 뱀의 몸과 겹치지 않는 빈 칸에만 생성됩니다.
- 벽 또는 자기 몸통과 충돌하면 게임 오버 상태가 되며, 최종 점수와 함께 다시 시작 버튼이
  표시됩니다.

## 구조

```
snake-game/
├── index.html      # 게임 entrypoint
├── styles.css       # 보드/HUD/오버레이 스타일
├── src/
│   ├── game.js       # 순수 게임 로직 (DOM 비의존, RNG 주입 가능)
│   └── app.js         # 렌더링 · 입력 · DOM 바인딩
├── tests/
│   └── game.test.js   # game.js 단위 테스트
└── README.md
```

## 테스트

`game.js`는 렌더링과 완전히 분리된 순수 로직이며, Node의 내장 테스트 러너로 실행합니다.
새 외부 런타임 의존성을 추가하지 않았습니다(패키지 설치 불필요).

```bash
node --test snake-game/tests/game.test.js
```

이동, 방향 반전 차단, 먹이 섭취/성장, 벽 충돌, 자기 충돌, 재시작(초기화) 시나리오를
검증합니다. 먹이 생성 위치는 주입 가능한 RNG를 통해 결정적으로 테스트됩니다.
